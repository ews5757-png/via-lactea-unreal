# Verified contribution scope

## Player

- Combat-related animation notifies and notify states
- Character animation state and locomotion enums

## Weapon

- Weapon and equipment base abstractions authored solely by `LDJ`
- Sword, shield, bow, hammer, great sword, gathering tool, and projectile implementations

## Excluded deliberately

- Five files created by `LDJ` but subsequently modified by teammates
- Fourteen files created by teammates and later modified by `LDJ`
- Team assets and Unreal `Content/`
- Project configuration, plugins, generated files, and SVN metadata

The selection is intentionally conservative so that this public-review snapshot does not present teammates' source files as the author's work.
